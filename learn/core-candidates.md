# Kärnan: kandidater

Generated by `node scripts/propose-core.mjs`. **Nothing here decides anything** —
`learn/core.json` does. This is the evidence, sorted so the hand pass has a
shortlist to argue with rather than 384 blank rows.

The question each row is asking:

> **If someone said "jag bor i X" or "vi ses vid X" on the phone, would you
> have to ask where that is?**

If yes, it is not core. Same shape as the *var bor du?* test `areas/areas.json`
uses for its promotions, and deliberately about people rather than about data.

`ja` / `?` / `nej` is the rule's guess from the band and the kind (see the head
comment in the script for the rule). `kärna` is what `learn/core.json` actually
says today — a `·` there against a `ja` here, or a `✓` against a `nej`, is a
place the hand pass overruled the rule. Those are the interesting rows.
